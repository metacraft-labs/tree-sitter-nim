# tree-sitter-nim

A Tree-sitter grammar for the Nim programming language, with an external scanner
supporting:

- INDENT/DEDENT layout parsing
- hard vs soft newlines
- nested block comments (`#[ ... ]#` and `##[ ... ]##`)

## Development with Nix (recommended)

This project provides a Nix flake for reproducible development environments on:

- x86_64-linux (Linux AMD64)
- aarch64-linux (Linux ARM64)
- x86_64-darwin (macOS Intel)
- aarch64-darwin (macOS Apple Silicon)

```bash
# Enter the development shell
nix develop

# Then run the usual commands
npm install
npm run generate
npm test
```

## Manual Prerequisites

- Node.js (for Node bindings and dev workflow)
- tree-sitter CLI:
  - `npm i -g tree-sitter-cli`

## Build / test (Node workflow)

```bash
npm install
npm run generate
npm test
```

## Notes

- `src/parser.c` and `src/node-types.json` are generated by `tree-sitter generate`.
- The external scanner is in `src/scanner.c`.
- Highlight queries live in `queries/`.
- Parse tests live in `test/corpus/`.

## Rust binding

From `bindings/rust`:

```bash
cargo test
```
